# 台灣詞庫與詞頻

`wisdom_taiwan.dict.yaml` 合併 McBopomofo、新酷音與本專案補充詞。
目前共有 153,468 個不同詞彙、161,805 組詞與讀音。新酷音補入 13,563 個不同詞彙。

- McBopomofo 保留既有規則：來源詞頻乘 10，限制在 100–10,000。
- 新酷音先合併相同詞與讀音，再按本來源最大詞頻做 `log1p` 正規化，映射到 100–1,000。
- 不同來源的相同詞與讀音取最大權重，不相加；手動補充詞權重至少 1,000。
- 保留來源明確提供的完整讀音，略過無法映射到目前 Rime 音節表的項目。
- 公開詞頻只提供基礎排序；不寫入個人詞典、選字次數或個人加權紀錄。

這套保守權重並非完整的語料統計校準，仍應用同音詞與整句測試持續調整。

來源版本、數量、權重規則與 SHA-256 記錄於 `wisdom_taiwan.manifest.json`；
著作權、修改說明及授權記錄於 `wisdom_taiwan.NOTICE.txt`。
新酷音 `tsi.csv` 標示 LGPL-2.1-or-later。隨附的 `wisdom_taiwan.sources.zip`
包含完整原始資料、授權、轉換工具與重建指令，Windows 與 Mac 打包均須保留。
